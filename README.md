#Разработка модульной архитектуры и организация обработки исключений (на примере Ювелирного магазина)

#Описание проекта
Автоматизация учета и расчета стоимости изделий в ювелирном магазине (JewelryStore).
#Структура решения (Solution)
Проект разделен на два основных модуля в решении:
1. `JewelryStore.Core` (Библиотека классов / Class Library):
`Models/` содержит базовые сущности предметной области (класс JewelryItem с атрибутами названия, материала и цены изделия).
`Services/` содержит бизнес-логику управления магазином (IJewelryServices, JewelryServices), включая методы добавления позиций и расчет стоимости с учетом скидок.
`Exceptions/` содержит кастомный класс ошибок JewelryException для валидации некорректных входных данных.
3. JewelryStore.Tests (Модульный тест / MSTest Project):
Содержит интеграционные и юнит-тесты (JewelryStoreTests.cs), проверяющие корректность работы бизнес-логики и перехват исключений через конструкции try-catch-finally.
#Инструкция по сборке и запуску
#Системные требования
Среда разработки: Visual Studio 2022 (или новее) / VS Code с установленным пакетом .NET SDK.
Целевая платформа: .NET 6.0 / .NET 8.0 (C#).
#Сборка и запуск проекта в Visual Studio
1. Склонируйте репозиторий или скачайте исходный код решения.
2. Откройте файл решения JewelryStore.sln в Visual Studio.
3. Дождитесь восстановления зависимостей (NuGet-пакетов) для тестового проекта.
4. Выполните сборку решения через верхнее меню: Сборка, далее Собрать решение или нажмите Ctrl + Shift + B.
#Запуск модульных тестов
1. Откройте вкладку Обозреватель тестов или Test Explorer через верхнее меню: Тест, далее Обозреватель тестов.
2. Нажмите кнопку «Запустить все тесты» или Run All Tests.
3. Убедитесь, что все тест-методы выполнились успешно и горят зеленым маркером.
4. Результаты перехвата исключений и работы блоков finally отобразятся в окне консольного вывода тестов (Standard Output).
